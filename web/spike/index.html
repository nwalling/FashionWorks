  • Drag-and-drop is the path that matters. Chromium's File System Access blocklist covers Program Files, so the modern picker fails on a default install. Drag-and-drop and this plain file input are not subject to it — that is what this page is checking.
  • Run in Chrome and Firefox. Both are Phase 0 exit criteria.
  • Must be served over http, not opened as a file:// URL — workers and WebAssembly need an origin. py -m http.server in this folder works.
